How Signoff solves it

  1. Parse the questionnaire — CSV, DOCX, XLSX or text. Every question gets an ID, nothing is paraphrased.
  2. You sign the mapping — a human decides, per question, which export file and columns count as proof. The machine never writes this table.
  3. Build offline — on your own machine, with your own CSVs. No server, no API, no LLM in the evidence path.
  4. Get the pack — dossier (HTML/PDF), answered questionnaire, gap list, hash-chained events, and a blank-signature Oversight Statement for a named human.
  5. Verify in one command — verify-pack replays the chain: every artifact matches its digest or the pack is rejected.

The engineering philosophy

Fail closed, never guess

Unmapped question → UNMAPPED, never a paraphrased answer. Unknown file → parse error, not silent drop. Missing timestamp → refusal to invent time.

Humans sign, machines prove

Every mapping row carries a name, a date, and a verification. The Oversight Statement is blank by design — a machine must never produce a signature.

Determinism is a feature

Injected clock, canonical JSON, SHA-256 hash chain. The same inputs always produce byte-identical artifacts, in front of an auditor.

Small and auditable

Python standard library plus one pinned PDF library. Every dependency hash-locked; the whole tool is reviewable in an afternoon.
